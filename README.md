## 📚 Projeto: Sistema de Controle de Empréstimos de Livros

Este projeto é uma aplicação web desenvolvida em ASP.NET Core MVC, com o objetivo de gerenciar o controle de empréstimos de livros em uma biblioteca ou acervo pessoal.

🔧 Funcionalidades principais:
- Cadastro de livros com informações como título, autor, editora, ano e edição.
- Registro de empréstimos e devoluções de livros.

- **Back-end:** .NET 8 (C#)
- **Banco de Dados:** SQL Server

- **Arquivos Estáticos:** Bootstrap, jQuery
